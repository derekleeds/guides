This site documents systems I build and operate: AI agent runtimes, memory and
retrieval tools, MCP integrations, homelab infrastructure, and the security
boundaries around them.

The audience is my future self and technical peers who want the reasoning as
well as the commands. A useful guide should define its terms, state the trust
boundary, and explain how to verify the result.

## What you will find

- practical setup and troubleshooting guides
- architecture explanations that separate products from patterns
- real operational examples from a working homelab
- links to primary documentation for details that change quickly

The source is available on [GitHub](https://github.com/derekleeds/guides)
under the [Apache License 2.0](https://github.com/derekleeds/guides/blob/main/LICENSE).
